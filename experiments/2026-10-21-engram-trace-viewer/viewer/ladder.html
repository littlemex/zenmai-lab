How to read this

Each block's output, passed through the model's final LayerNorm and output head, is a guess at the next token (LogitLens). A prediction settles at the first block from which that top-1 guess equals the last block's top-1 and stays equal. The blocks above still run and can still change the probabilities; settling only says that their top-1 no longer changes.

The text is shaded green where the first model settles at an earlier block than the second, and underlined red where later. The bars are the blocks above the settled one, per position. The summary counts every position, and separately the positions where both models end on the token that actually comes next.

The counts describe this one text and one seed; when the text was generated by one of the models, its own continuation favours it. Beside the text, one position: what each block predicts, block 0 at the bottom, and where the Engram output is added. Space plays through the text.
