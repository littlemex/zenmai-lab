How to read this

Each column is the row range of one (n-gram size, hash head) pair in the layer's table, first row at the bottom.

A mark is a row read by a position up to the current one. Marks that overlap glow brighter, but one mark spans about a hundred thousand rows, so overlap is not proof of the same row: the table below and the dashed arcs show exact reuse.

Solid lines join the current token to the rows it reads. A dashed yellow arc means an earlier token read that row first.

The strip on the left edge of a column is the rank that holds those rows at the chosen world size.
